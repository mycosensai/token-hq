Buyback & burn — how it works here

A buyback-and-burn only means something if the burn is provable. This project's rule: never report a burn that isn't reflected in the supply. On Solana that means the token's supply figure itself drops (checked above, live). On Base, tokens are sent to the dead address and the balance is shown above. Each future burn event will be listed here with its transaction link so anyone can audit it.

Airdrop to random holders — the honest version

The random draw uses a future Solana slot hash (or an EVM blockhash) — published before it exists — so the selection is provably unpredictable and re-computable by anyone afterwards.

Verifiable draw — the recipe

1. Announce: "draw will use the slot hash of slot S" (S is ~1 hour in the future).
2. Wait for slot S to exist on chain.
3. seed = sha256(slot_hash(S))          ← visible to everyone forever
4. winner_i = holders[ seed mod N ]     ← deterministic, recomputable by anyone
5. Publish the transfer transactions.   ← on-chain proof of delivery
No server picks winners. No admin key can bias the draw. Anyone can recompute step 3–4 from public data and confirm the winners were honest. A dedicated claim contract (Merkle-based) can be added later; this page will carry its address once it exists.
